### CONCRETE BLOCKERS

**1. Reimplementation Bug: WL Kernel and Topology use a Name-Occurrence Graph, NOT a Call Graph**
*   **Defect:** `PILOT-RESULTS.md` claims "my WL-kernel reimplementation gives AUC 1.00", attributing this to "matcher-dependence" and asserting that structural similarity can wildly contradict depending on the algorithm. Furthermore, `SPECIFICATION.md` §5.2 claims these metrics are "renaming-invariant by construction."
*   **Evidence:** In `pilot/structural.py` lines 34-35, `build_call_graph` lumps all functions sharing a name into the exact same node (`defined.add(n.name)`). Then, in lines 46-47, it connects callers to callees purely based on string name (`g.add_edge(self.stack[-1], callee)`).
*   **Why it's wrong:** This logic collapses all identically named methods (e.g., every `reset`, `feed`, or `__init__` across all classes) into single super-nodes. The resulting topology is entirely an artifact of shared identifier vocabulary, completely defeating the "renaming-invariant" claim. The AUC of 1.0 is not a profound finding about "matcher-dependence," but merely the result of `chardet` lineage sharing the same method names while `charset_normalizer` does not.

**2. Overclaim: Cross-Language Capability is Completely Fabricated**
*   **Defect:** `SPECIFICATION.md` v0.6 claims "cross-language ST/PB enabled ... via per-language AST walkers + a language-agnostic structural-descriptor layer".
*   **Evidence:** There is zero code backing this. All metric scripts strictly depend on Python's built-in `ast` module. See `pilot/pilot_harness.py` line 86 (`tree = ast.parse(open(path, 'rb').read())`), `pilot/structural.py` line 22, and `pilot/residual.py` line 61.
*   **Why it's wrong:** The harness is entirely Python-specific, making the cross-language design claims in the spec fabricated.

**3. Overclaim/Cherry-picking: The AI Rewrite is NOT "Below Independent" for BHd**
*   **Defect:** `PILOT-RESULTS.md` asserts for the BHd metric: "EVOLVED 0.605 vs INDEPENDENT ~0.42, with the AI rewrite at 0.135 — below independent."
*   **Evidence:** While the AI rewrite `v6-v7` does have `BHd = 0.1345`, the `pilot/results.json` output generated by `pilot_harness.py` shows the three INDEPENDENT pairs scored `0.4215` (v5-csn), `0.4304` (v6-csn), and **`0.0717` (v7-csn)**. 
*   **Why it's wrong:** Summarizing the INDEPENDENT baseline as "~0.42" conveniently drops the `v7-csn` pair. Since `0.0717` is below `0.135`, the claim that the AI rewrite sits "below independent" is factually false and relies on cherry-picked data.
